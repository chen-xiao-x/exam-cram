## 现象（用户截图）
- 左侧章节列表 20+ 个，**大量重复**：
  - "7.2 客户关系管理" 出现 5 次
  - "2. 供应链管理与信息系统" 出现 2 次

  - "导入章节"（AI 默认标题）
  - "1906-1949" / "1949-1979" / "1979-1995" / "1995-2006"（PPT 时间线被当章节标题）
  - "01. 核心痛点：隐形的巨额..."（被截断）
  - "1. Wal-Mart的采购人员从..."（被截断）
- **卡片内容是错的/杜撰的**：
  - "在 App 下单一杯奶茶，从你点击'下单'到" — 这是 AI 杜撰的奶茶场景
  - "阶段 1：用户下单与支付" — 也是杜撰的应用阶段
  - 全部 tag 都是"概念" — **没用上 5 类多粒度**
